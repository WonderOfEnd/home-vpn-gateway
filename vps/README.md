# Внешний сервер

Сверено 31 октября 2026 года: Debian 11, x-ui, Xray под управлением панели,
mtg и Fail2ban. Home использует VLESS/REALITY на TCP 443; MTProto слушает TCP 8443.

В systemd/ сохранены определения служб x-ui и mtg. MTG_SECRET placeholder
необходимо заполнить локально; реальный секрет в Git не хранится.

Эти шаблоны не содержат установщики, клиентскую базу x-ui, UUID, сертификаты
и закрытые ключи. Восстановление панели требует её приватного экспорта.
Синхронизация Git не меняла службы или пакеты VPS.
