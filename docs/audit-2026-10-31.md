# Сверка серверного шлюза home: 31 октября 2026 года

Репозиторий хранит конфигурацию домашнего VPN-шлюза: Xray, DNS/Pi-hole,
iptables, policy routing, интерфейс исключений и серверные правила UDP.

Базовый опубликованный конфиг от 4 октября не содержал последующих изменений
работающего шлюза. По серверу сверены следующие компоненты.

| Компонент | Сохранённое состояние |
| --- | --- |
| TCP и DNS | Прозрачный TCP inbound и локальный DNS relay через туннель |
| UDP TPROXY | Inbound 12346, XRAY_UDP, fwmark 1 / route table 100 |
| TruckersMP | Четыре точечных адреса в mangle PREROUTING |
| Discord | Определение IP Discovery и conntrack mark с перенаправлением через Xray |
| QUIC | Существующая блокировка UDP 443 на FORWARD |
| Журналы Xray | access none, error warning; отключение access log от 27 октября |
| Исключения сайтов | Сверены скрипты и служба LAN UI на 8090 |
| Pi-hole | Compose template, upstream 127.0.0.1#5353, web ports 8080/8443 |
| Загрузка служб | Сохранены systemd units, drop-in Xray и sysctl IPv4 forwarding |

## Проверки

- Xray установленной на home версии принял шаблон с вымышленными параметрами:
  Configuration OK, без запуска туннеля и без замены рабочего конфига.
- Снимок iptables разобран и переведён в nft-синтаксис без применения правил.
- Docker Compose config проверил шаблон Pi-hole без запуска контейнера.
- JSON, Python AST и shell syntax прошли проверки.
- Для Discord получен корректный UDP-ответ за 72–73 мс, в клиенте подтверждены
  RTC_CONNECTED голоса и трансляции; пользователь подтвердил звук.

## Ограничения и открытые вопросы

- Автозапуск правила Discord включён, реальную перезагрузку home для проверки
  не выполняли. Серверные службы при синхронизации репозитория не менялись.
- На home ранее найден reboot-required после обновления ядра; перезагрузка
  в рамках сверки не выполнялась.
- Снимок iptables сохраняет существующие Docker chains и повторяющиеся live rules.
- Пароли, UUID, ключи доступа, личные исключения сайтов и базы Pi-hole не
  экспортировались. Для восстановления нужны соответствующие локальные данные.
